# 主 Agent：通用 Agent 的限定案例

分析材料为 [[wiki/papers/harness/tools/Toolathlon|S076 Toolathlon]]，锁定arXiv v2；原文、hash、实际阅读范围和实验定位归唯一来源页。本轮不扩展到具身/医学/全部个人助理。

**任务与成效→**Notion HR：PDF简历→Notion岗位与候选人表→邮件；刊载Claude-4-Sonnet轨迹45次工具调用后成功，作为可行性例子；108任务统一框架三次评测，Claude-4.5-Sonnet pass@1 38.6±2.7%，pass^3 20.4%，不把总体成功率贴到此单例。

**环境条件→**可读原件与岗位数据，现成工具及权限，预配置任务相关服务器，真实软件初始化；独立评测脚本在末端验收，不能说agent随时拥有它，也不把容器重置当在线回滚。

**关键机制→**模型先探索结构再匹配对象，执行失败后修改API；harness继续错误轨迹并提供分页、历史管理、工具执行。跨接口新增对象身份、格式和覆盖约束。局部判断正确不等于全部副作用正确。

**model/harness贡献→**成功轨迹支持组合机制可工作，不证明任何单组件必要或优于固定流程。统一框架模型差异提示策略能力重要，但无harness替换与训练控制，当前瓶颈只能条件性判耦合。

**支持证据→**Table3 p.7；§2.4 p.5；App.B pp.14–15；Notion HR pp.31–36；App.C.2 p.16漏项与早停；App.E.2 p.18及pp.27–30上传缺图片。

**结论边界→**未找到本论文的动态/固定等工具等预算对照；工程错误保护不是经消融验证的主导收益；长输出相关性、GPT-5提高reasoning无收益均不证明普遍因果。内化训练未测。无需为补出肯定结论增读Magentic-One，本轮保持6篇。
