# Lint 清单

规则入口：[[AGENTS#6. Lint：结构与证据健康检查|AGENTS · Lint]]。

| 检查 | 通过条件 | 不通过时 |
| --- | --- | --- |
| Raw 完整性 | 文件存在；SHA-256 与论文页或归档日志一致 | 报告差异，不“修复”原件或改哈希掩盖差异 |
| 论文唯一性 | 同一论文仅一张论文页；版本分别登记 | 合并生成内容、修复链接，保留各版来源 |
| 来源与范围 | 重要主张有直接来源定位；未读工作不计作直接证据 | 降级为转述/待核验或回读原文 |
| 文件与锚点 | 内部链接目标及标题存在；PDF 页码有效 | 修正路径、大小写、标题或页码 |
| 索引覆盖 | 每张知识页在 [[wiki/index\|索引]] 中有链接和摘要 | 补充或修正目录 |
| 图与内容 | 无孤立知识页、空白页面/目录；相关主题与论文互链 | 连接有意义的内容，移除空壳或并入现有页 |
| 语义一致性 | 术语、条件、推断标签一致；冲突被明确保留 | 对照原文，记录分歧和缺少的证据 |
| 单篇研究分析 | 问题、机制、前提、证据范围与本库影响清楚；按论文类型调整 | 回原文补充实质解释，不为填模板编造信息或强凑 gap |
| 跨论文可比性 | 比较交代任务、模型、harness、预算、指标及改变对象 | 限定比较范围，区分条件差异与真正冲突 |
| 候选研究问题 | 区分理解/材料缺口与候选研究缺口，有依据、反对意见、下一步及状态 | 降级或补查；不把“本文没做”改写成“领域无人做过” |
| 查新边界 | 有日期、渠道、查询词、相关结果、全文可达性与实际核读范围 | 标记待查新/待核验，不以搜索未找到证明不存在 |
| 多 Agent 证据 | 首轮初稿隔离，共同证据版本一致；同源不重复计数，模型共识不充当来源 | 同步证据、保留分歧；有疑点时派独立原页核查 |
| 协作交付 | 同模型任务、唯一论文/来源 ID、共享文件串行更新；摄入状态与实际完成度一致 | 查明重复、覆盖或未整合项，修复后再验收；不得回收已分配 ID |
| 轮次边界 | 范围、总预算及补读可回查，达到停止条件后收束 | 交代未完成项，不静默启动下一轮或扩大所有子方向 |
| 图文同步 | 图、摘要和正文含义一致；推断与边界可见 | 同步更新；暂不能更新的视图标注并退出主入口 |
| 阅读结构 | 图就近解释具体问题；正文补充必要内容，没有重复的“前置图解 + 原长文” | 重排解释顺序、去除冗余；没有解释价值的图不保留 |
| Obsidian 语法 | 表格内别名分隔符转义；Mermaid、公式及 Callout 结构正确 | 修复后在应用中检查实际渲染 |
| 阅读与操作 | 按阅读表达清单检查图表、卡片、折叠、来源跳转及正常/窄分栏阅读 | 修复截断、拥挤或歧义；明确未测范围，不用浏览器结果替代 |
| 维护记录 | 更新日期准确，[[wiki/log\|日志]] 只追加 | 追加更正，不回写历史 |

检查后更新受影响的索引和交叉引用。独立全库检查或发现重要问题时，按 [[AGENTS#7. 索引与追加日志|日志规则]] 简短记录范围、主要发现与处置；随 Ingest/Query 进行的局部检查并入该次操作，无发现的常规局部检查不单独记日志。区分结构检查与学术核验，不把链接有效当成学术验证。当前无需为这一清单引入永久脚本；规模增长后再添加工具。

阅读检查的具体步骤见 [[workflows/presentation|阅读表达清单]]。文件检查、图文语义核对和 Obsidian 实测分别说明，不以任何一种代替其他检查。

旧日志中指向用户已明确撤下的非 Raw 展示产物的链接，须有追加日志说明原路径、原因与替代入口，作为历史撤下项单独报告；不得自动重建。当前知识页和索引仍须清除这些入口，其他断链照常修复。
